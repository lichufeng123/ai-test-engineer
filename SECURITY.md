# Security Policy

Do not file public issues containing credentials, tokens, cookies, private endpoints, personal data, customer data, or unredacted execution evidence.

For a vulnerability or accidental disclosure, contact the repository maintainers privately through the GitHub security-advisory workflow. Include a minimal reproduction and the affected version; redact sensitive values.

Maintainers should rotate exposed credentials, remove leaked data from public history when appropriate, and publish a fix or advisory after coordinating remediation.
