# Stagehand Adapter

Stagehand 只承担受控自愈：在Playwright定位器、等待条件或已知瞬态弹窗失效时生成修复候选。它不能自由改变正式测试行为。

## 允许修复

- 元素角色、Test ID、Label、稳定文本或DOM层级变化导致的定位器失效。
- 页面真实异步条件变化导致的等待条件失效。
- 已登记瞬态弹窗、引导层或通知遮挡。

## 禁止修复

- 修改预期结果或业务规则。
- 删除、弱化或跳过正式断言。
- 把失败改成通过、阻塞或不适用。
- 对提交、收款、通知、删除、关联等写操作盲目重试。
- 未经审核扩展数据范围或账号权限。

## 修复闭环

```text
Playwright失败证据
→ Chrome DevTools MCP诊断（按需）
→ Stagehand observe/act生成最小修复候选
→ 代码审查
→ Playwright单用例验证
→ Playwright影响回归
→ 更新执行资产与哈希回执
```

## 接入

在项目私有自动化仓库锁定精确版本和模型版本。模型Key、Browserbase凭据、Cookie和内部地址只通过运行时安全配置提供。若使用云浏览器，必须先通过内部数据与网络合规审批；默认优先本地执行。

Stagehand输出必须包含原失败证据、建议变更、受影响Case ID、单用例验证和影响回归结果。没有Playwright验证回执时，修复状态只能是候选。
