- 范围：新增 `.agents/skills/test-recording-generate/`，由唯一 Skill 源码分发；`ai-test-workflow`、`AGENTS.md` 增加路由，原 `ai-test data-generate` 的表格/JSON 行为不变。
- 测试先行：新增录音生成器测试，首次运行因尚无脚本失败；随后实现离线脚本，覆盖输入拒绝、未知字段、重复 ID、禁止覆盖、失败无部分交付、真实合成/静音编码回读、待确认和已声明预期的区分。
- 第三次扩展（同一未发布变更集内，用户明确要求：“每段录音的文字内容要放在一个文档，以后都要注意这个约束”）：每次生成必须同时交付 `recording_transcripts.md`，逐段列出文件名、类型、时长、说话人、音色与完整台词。测试先行：新增文档断言后 3 项失败，实现后 8 项通过；清单同时回写 `transcripts` 文件名与生成时间，交付时缺逐字稿文档视为不合格。
- 第二次扩展（同一未发布变更集内）：新增多人 `dialogue`（逐轮 speaker/text/可选 voice + 轮次停顿）与 `min_duration_seconds`/`max_duration_seconds` 长度门禁，并新增可听性检查（平均音量低于 -60 dB 视为合成失败）。同类测试先行：实现前对话与长度用例失败，实现后 8 项通过；本地实测有过短样本被长度门禁阻断且未交付任何文件；生效的时长下限与实测平均音量回写清单，便于逐条追溯。
- 同步：README（中英）、`docs/FRAMEWORK.md`、数据策略、Skill 分发文档与版本元数据更新至 0.13.0a2。现有安装用户需重新运行受控 Skill 安装；不覆盖旧目录，不变更用户级 Skill 或发布插件。
- 依赖：仅语音合成需 macOS `say`；音频编码和探针需要 `ffmpeg`/`ffprobe`。依赖缺失则阻塞，未内置其他平台 TTS 或联网回退。生成人工审核前的音频不能充当标签通过证据。
- 校验：本地全量 `python3 -m unittest discover -s tests -p 'test_*.py'` 通过（185 项）；`docs-check`、`skills-check`、`git diff --check` 通过；离线示例与一次 12 段、总时长 18.8 分钟的批量生成均通过时长、可听性与逐字稿文档校验，且同一 spec 重跑后音频哈希完全一致（可复现）。均不代表真实系统的自动标签或五维记忆测试通过。
