# 测试数据策略

## 默认自主生成

AI可根据模板、Schema、需求和页面校验自主生成正常、异常、边界、重复、混合、特殊字符、空文件、损坏文件、数量和性能数据。

## 生成要求

每个数据文件必须有稳定fixture ID、语义名称、用途、预期、SHA-256、写入影响、适用环境和清理策略。生成后要重新打开或解析，确认文件本身有效。

## 环境复用

跨环境复用生成规则和模板，不复用数据库ID、会话或凭证。名称建议包含环境、日期、用例ID和随机后缀。

## 需要确认

涉及真实客户、真实员工、金额、库存、生产批量写入、删除覆盖、通知或未知业务语义时向产品经理确认。
